# Death Clips

A RuneLite plugin that plays your own custom death sounds whenever your local player dies.

## Features

- Selected, Random, and Shuffle playback modes
- Prevent consecutive repeats
- Volume control
- Test playback
- Import your own WAV files
- Delete selected sounds from the plugin
- Open the local sounds folder

## How to use

1. Open **Death Clips** from the RuneLite sidebar.
2. Click **Import WAV...** and choose a sound.
3. Add as many sounds as you want.
4. Choose **Selected**, **Random**, or **Shuffle**.
5. Set your volume and use **Test Playback** if you want to preview it.
6. When your local player dies, Death Clips plays a sound using the selected mode.

## Audio format

WAV files are currently supported.

PCM 16-bit at 44.1 kHz or 48 kHz is recommended for the best compatibility.

## Local sounds

Imported sounds stay on your computer in your RuneLite data folder. No death sounds are bundled with the plugin.
